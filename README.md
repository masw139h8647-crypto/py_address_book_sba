# Python通訊錄管理系統

  一個使用 Python 開發的通訊錄。最大特色是**動態欄位設計**
  可以在程式執行時隨時增加、刪除、調整欄位順序，並設定每個欄位的資料類型和驗證規則，完全不用改程式碼。

## 功能

- **動態欄位管理**  
  透過設定視窗自由增刪欄位、排序，並設定是否只能輸入數字，可以设置为文本输入栏/下拉式選單。

- **自訂驗證規則**  
  每個欄位可單獨設定：
  - 字數／數值範圍
  - 必須包含／不可包含的關鍵字
  - 純數字模式

- **資料自動儲存**  
  所有通訊錄資料和欄位設定都會于关闭时自動存成 JSON 檔，重新開啟程式後完整還原。

- **搜尋與分頁**  
  - 支援多關鍵字搜尋（包含／排除）输入内容，也可于搜尋栏输入!ERROR搜尋（包含／排除）不符合所设定的有效性检验的联络人资料，然后自動分頁顯示結果。
  - 进行搜尋时，如果未输入任何搜尋内容，则会清除所有搜尋内容
  - 可以输入页码跳转

- **零依賴**  
  只使用 Python 內建函式庫，不需另外安裝任何套件。
